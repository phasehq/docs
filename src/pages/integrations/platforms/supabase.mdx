# Supabase Edge Functions

You can use Phase to sync secrets to your Supabase project, where they are available to your Edge Functions at runtime.

<DocActions />

<Warning>
  When secret syncing is enabled, secrets stored inside Phase will be treated as
  the source of truth. Any secrets on the target service will be overwritten or
  deleted. Please import your secrets into Phase before continuing.
</Warning>

<Note>
  Secrets prefixed with `SUPABASE_` are reserved by Supabase and are managed
  automatically for every project (for example `SUPABASE_URL` and
  `SUPABASE_ANON_KEY`). Phase will never delete these, and any secrets in
  Phase whose keys start with `SUPABASE_` will be skipped during the sync.
  Skipped keys are listed in the sync logs.
</Note>

### Prerequisites

- Sign up for the [Phase Console](/quickstart) and [create an App](/console/apps#create-an-app).
- Enable Server-side Encryption (SSE) for the App from the [Settings](/console/apps#settings) tab.

## Step 1: Authentication

### Create a Supabase access token

1. Log in to your [Supabase Dashboard](https://supabase.com/dashboard), click on your avatar in the top right and select **Account**.

![Supabase account menu](/assets/images/platform-integrations/supabase/supabase-account-menu.png)

2. Go to the [Access Tokens](https://supabase.com/dashboard/account/tokens) tab and click **Generate New Token**. Give it a descriptive name, choose an expiry and click **Generate token**. Copy the token — you will not be able to see it again.

![Generate new token](/assets/images/platform-integrations/supabase/supabase-generate-token.png)

<Note>
  Supabase requires an expiry on new access tokens (up to 1 year with a custom
  date). Once the token expires, syncs will fail with an authentication error
  until you update the stored credentials with a new token. Access tokens also
  grant access to the Supabase Management API for every project your account
  can access, so consider creating the token from a service account with
  access scoped to the projects you want to sync secrets to.
</Note>

### Store authentication credentials in Phase

<Note>
  Your credentials are kept secure with robust application-layer encryption.
  Phase encrypts your credentials directly in the browser and only decrypts them
  in memory to perform sync operations. Your credentials are never stored in
  plaintext.
</Note>

1. Go to **Integrations** from the sidebar and click on **Third-party credentials** in the integrations tab.

![Go to integrations](/assets/images/platform-integrations/integrations-sidebar.png)

2. Click on **Supabase**.

![supabase-create-creds](/assets/images/platform-integrations/supabase/add-credentials-supabase-1.png)

3. Enter your Supabase `Access Token` from the previous step. Enter a descriptive name and click **Save**.

![supabase-input-creds](/assets/images/platform-integrations/supabase/add-credentials-supabase-2.png)

Your credentials will be encrypted and saved. You can view and manage these credentials under *Service Credentials* in the *Integrations* screen.

## Step 2: Set up a secret sync

1. Go to your App in the Phase Console and go to the **Syncing** tab. Select **Supabase Edge Functions** under the 'Create a new Sync' menu.

![create supabase sync](/assets/images/platform-integrations/supabase/create-sync-supabase-1.png)

2. Choose the credentials you added in the previous step as the authentication mode, and click **Next**.

![select supabase creds](/assets/images/platform-integrations/supabase/create-sync-supabase-2.png)

3. Next, configure the source and destination for your secrets. Pick an Environment from your App as the source, along with the Path if you have a specific folder you want to sync from. Then choose a Supabase project from the dropdown and click **Create**.

![configure supabase sync](/assets/images/platform-integrations/supabase/create-sync-supabase-3.png)

4. Once set up, your secrets will automatically be synced to the chosen Supabase project. You can manage your sync from the *Syncing* tab of your App, or from the *Integrations* screen.

![supabase sync card](/assets/images/platform-integrations/supabase/supabase-sync-card.png)

Synced secrets are available to your Edge Functions without requiring a redeploy. You can verify them from your project's **Edge Functions → Secrets** page in the Supabase Dashboard, or with the Supabase CLI:

```fish
supabase secrets list --project-ref <your-project-ref>
```

You can access the synced secrets in an Edge Function via environment variables:

```ts
Deno.serve(async () => {
  const stripeKey = Deno.env.get('STRIPE_SECRET_KEY')

  return new Response(
    JSON.stringify({ stripeKeyIsSet: Boolean(stripeKey) }),
    { headers: { 'Content-Type': 'application/json' } },
  )
})
```
